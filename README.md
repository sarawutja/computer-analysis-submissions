# ระบบส่งงานนักศึกษา — 09412315 คอมพิวเตอร์และการวิเคราะห์ข้อมูล
**(Computer and Data Analysis) · ภาคการศึกษา 2/2569 · ผู้สอน: ผศ.ดร.ศราวุธ ใจเย็น**

ชุดไฟล์ระบบส่งงานออนไลน์แบบแยกหน้าเว็บ (**GitHub Pages**) และระบบหลังบ้าน (**Google Apps Script + Google Sheets + Google Drive**) พร้อมระบบเปลี่ยนชื่อไฟล์อัตโนมัติ สร้างโฟลเดอร์งานอัตโนมัติ ตรวจสอบส่งช้า และแผงควบคุมตรวจให้คะแนนสำหรับอาจารย์ผู้สอน

---

## รายการไฟล์ทั้งหมดในชุดนี้
1. `Code.gs` — โค้ดระบบหลังบ้านสำหรับวางใน **Google Apps Script** (มีฟังก์ชัน `setupSystem()` กดรันครั้งเดียวเพื่อสร้างแท็บ Google Sheet และโฟลเดอร์ Google Drive ให้อัตโนมัติ)
2. `index.html` — โครงสร้างหลักของหน้าเว็บไซต์
3. `styles.css` — ชุดรูปแบบการแสดงผลโทนสีสว่าง (ขาว-ฟ้า-น้ำเงิน) รองรับคอมพิวเตอร์และมือถือ
4. `app.js` — สคริปต์ฝั่งหน้าเว็บสำหรับเชื่อมต่อกับ Google Apps Script Web App API
5. `README.md` — คู่มือการติดตั้งและใช้งานฉบับนี้

---

## โครงสร้างฐานข้อมูล Google Sheet (สร้างอัตโนมัติจาก `setupSystem`)
ระบบจะสร้าง 4 แท็บดังนี้:
- **`Students`** — `student_id`, `full_name`, `username`, `password` (รายชื่อและบัญชีเข้าสู่ระบบของนักศึกษา)
- **`Teachers`** — `teacher_name`, `username`, `password` (บัญชีอาจารย์ผู้สอน — สามารถเปลี่ยนรหัสผ่านในชีตได้โดยตรง)
- **`Assignments`** — `assignment_id`, `title`, `description`, `max_score`, `deadline`, `status`, `folder_id`, `created_at`
- **`Submissions`** — บันทึกประวัติการส่งไฟล์ ลิงก์ไฟล์บน Drive สถานะส่งช้า (`TRUE`/`FALSE`) สถานะการตรวจ (`submitted`/`graded`) คะแนน และข้อเสนอแนะ

## ขั้นตอนที่ 1: ติดตั้งระบบหลังบ้าน (Google Sheet + Google Apps Script)

1. สร้าง **Google Sheet ใหม่** ในบัญชี Google ของอาจารย์ ตั้งชื่อไฟล์ เช่น `09412315_ระบบส่งงาน_2-2569`
2. ที่แถบเมนูด้านบน เลือก **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ออกทั้งหมด แล้วคัดลอกโค้ดทั้งหมดจากไฟล์ **`Code.gs`** ในชุดนี้ไปวาง จากนั้นกดบันทึก (`Ctrl + S`)
4. *(ไม่บังคับ)* หากต้องการเลือกโฟลเดอร์ Google Drive ที่มีอยู่เดิมเป็นโฟลเดอร์หลัก ให้นำ Folder ID (ชุดตัวอักษรหลัง `/folders/` ใน URL ของโฟลเดอร์) ไปวางในบรรทัด:
   ```javascript
   const ROOT_FOLDER_ID = "ใส่_FOLDER_ID_ที่นี่";
   ```
   *(หากเว้นว่าง `""` ไว้ ระบบจะสร้างโฟลเดอร์ชื่อ `09412315_ระบบส่งงาน_2-2569` ใน Google Drive ให้อัตโนมัติ)*
5. เลือกฟังก์ชัน **`setupSystem`** ที่แถบเครื่องมือด้านบน แล้วกดปุ่ม **เรียกใช้ (Run)**
   - ระบบจะขออนุญาตเข้าถึง Google Sheets และ Google Drive ให้กด **Review Permissions > เลือกบัญชี Google ของอาจารย์ > Advanced > Go to ... (unsafe) > Allow**
   - เมื่อรันเสร็จ ระบบจะสร้างแท็บทั้ง 4 แท็บ พร้อมโฟลเดอร์ย่อย `งาน-01`, `งาน-02`, `งาน-03` ใน Google Drive ให้อัตโนมัติ
6. กลับไปที่ไฟล์ Google Sheet:
   - เปิดแท็บ **`Teachers`** เพื่อเปลี่ยน `username` และ `password` ของอาจารย์ (ค่าเริ่มต้นคือ `teacher` / `admin1234`)
   - เปิดแท็บ **`Students`** เพื่อกรอกรายชื่อนักศึกษา รหัสนักศึกษา `username` และ `password` ของนักศึกษาทุกคน (ลบข้อมูลตัวอย่าง 3 แถวแรกออกได้)

## ขั้นตอนที่ 2: เผยแพร่เป็น Web App (Deploy)

1. ในหน้า Google Apps Script กดปุ่ม **ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดรูปเฟือง เลือกประเภทเป็น **เว็บแอป (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `09412315 Submission API v1`
   - **ดำเนินการในฐานะ (Execute as):** **ฉัน (Me)**
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)**
4. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** แล้วคัดลอก **URL ของเว็บแอป (Web app URL)** (จะลงท้ายด้วย `/exec`)

> **หมายเหตุสำคัญ:** หากในอนาคตมีการแก้ไขโค้ดใน `Code.gs` ต้องกด **Deploy > Manage deployments > แก้ไข (รูปดินสอ) > เปลี่ยน Version เป็น New version > Deploy** เพื่อให้โค้ดใหม่มีผลใช้งานจริง

---

## ขั้นตอนที่ 3: เชื่อมต่อหน้าเว็บและนำขึ้น GitHub Pages

1. เปิดไฟล์ **`app.js`** ด้วยโปรแกรมแก้ไขข้อความ (เช่น Notepad, VS Code)
2. แก้ไขบรรทัดที่ 7 โดยนำ Web App URL จากขั้นตอนที่ 2 มาวางแทนที่:
   ```javascript
   const API_URL = "https://script.google.com/macros/s/xxxxxxxxxxxxxxxxx/exec";
   ```
   แล้วบันทึกไฟล์
3. สร้าง Repository ใหม่บน GitHub (ตั้งเป็น **Public**) เช่น `rmutt-09412315-submit`
4. อัปโหลดไฟล์ฝั่งหน้าเว็บทั้ง 4 ไฟล์ขึ้นไปที่หน้าหลักของ Repository (ไม่จำเป็นต้องอัปโหลด `Code.gs`):
   - `index.html`
   - `styles.css`
   - `app.js`
   - `README.md`
5. ไปที่ **Settings > Pages** ตรงหัวข้อ **Build and deployment > Branch** เลือก `main` และ `/ (root)` แล้วกด **Save**
6. รอประมาณ 1–2 นาที เปิดใช้งานเว็บไซต์ได้ที่ `https://<ชื่อผู้ใช้-GitHub>.github.io/<ชื่อ-repository>/`
